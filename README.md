# Автоматический расчёт заказов поставщикам

Сервис для менеджера отдела закупа ТОО «Электрокомплект»: по истории продаж, остаткам,
товарам в пути, сезонности и кратности поставщика формирует рекомендованные заказы
поставщикам (IEK, Systeme Electric) с обоснованием по каждой позиции. Разовые крупные
продажи исключаются из регулярной потребности, упущенный спрос в периоды отсутствия
товара компенсируется. Заказ не отправляется поставщику автоматически — только после
утверждения менеджером.

> README дополняется по ходу разработки.

## Технологии

Python 3.10+, Django 5, pandas, numpy, openpyxl, SQLite.

## Установка и запуск

```bash
python -m venv venv
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ — на главной видно, какие файлы данных загружены.

## Параметры окружения

Переменные окружения не используются. Все настройки — в `constants.py`.
Ключи API (необязательно) — в `local_constants.py`, см. `local_constants.example.py`.
Без ключей сервис работает полностью.

## Данные

Выгрузки партнёра лежат в `data/demo/<поставщик>/` (имена переведены в латиницу):

| Файл | Содержимое |
|---|---|
| `sales_transactions.xlsx` | построчные расходные накладные: дата, номер, код 1С, количество |
| `sales_monthly.xlsx` | продажи в штуках, SKU × месяц |
| `stock_monthly.xlsx` | остатки, SKU × месяц |
| `in_transit.xlsx` | товар в пути с датами поступления |
| `moq.xlsx` | минимальная партия / кратность |
| `seasonality.xlsx` | продажи в деньгах по месяцам и годам |
